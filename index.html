1. Новый файл MathPlotModel.kt (15 KB)

object MathPlotModel {
  data class Plot(id, keywords, genre, title, chars)
  data class PlotStage(stage, keywords, description)
  data class ScoredPlot(plot, score, matchedKeywords)

  // Жанр → запросы Флибусты
  GenreFlibustaMapper.getQueriesForGenre(genre):
    Детектив → [детектив, Sherlock Holmes, Акунин]
    Фантастика → [фантастика, Стругацкий, Лукьяненко]
    Роман → [любовный роман, любовь, Ремарк]
    ...

  // Семантика
  extractKeywords(text) → TF
  calculateSimilarity(Q,K):
    Jaccard = |Q∩K|/|Q∪K|
    score = Jaccard*2 + |Q∩K|*0.3 + genreMatch*0.5 + important*0.2

  selectBestPlot(intro, genre, plots):
    qKeywords = extract(intro)
    scored = plots.map { Sim(qKeywords, plot.keywords) }
    return max(scored) if score > 0.2

  buildPlotGraph(bestPlot, introKeywords, genre):
    combined = intro.take(4) + bestPlot.keywords.take(4) + genreKeywords.take(2)
    return 5 stages: завязка, развитие1, развитие2, кульминация, развязка
    Детектив: Звонок про kw1 → Улика kw2 → Подозреваемый kw3 → Правда kw4 → Справедливость
    Роман: Встреча kw1 → Чувство kw2 → Разлука kw3 → Выбор kw4 → Любовь

  Coherence = 0.5*Lexical + 0.35*Entity + 0.15*Temporal
}

🚀 Как работает теперь (пошагово)

  1. Пользователь выбирает жанр «Детектив» в спиннере
  2. onGenreSelectedForLearning("Детектив") → проверяет сколько детективов изучено
  3. Если <3 → GenreFlibustaMapper.getQueriesForGenre("Детектив") = [детектив, Sherlock Holmes, Акунин, Донцова, Чейз]
  4. Для каждого query: OpdsFetcher.searchFlibusta(query, http://flibusta.net/opds) → список книг
  5. Берет первую с downloadLinks, fetchBookText() → текст FB2/EPUB/TXT
  6. LearningManager.learnFromText() → извлекает H,P,F,K, сохраняет в learned_heroes.json, learned_places.json, learned_phrases.json, learned_plots.json + plots_Детектив.json + learned_plots_detailed.json (с жанром)
  7. Пользователь вводит вступление: «Ночью в Полоцке пропала девушка, оставив коробку пиццы и перо ворона...»
  8. Нажимает «Генерировать» → generateStory() загружает detailedPlotsByGenre("Детектив") = 5 сюжетов
  9. MathPlotModel.extractKeywords(вступление) = [ночью, Полоцке, пропала, девушка, коробка, пиццы, перо, ворона]
  10. selectBestPlot() считает Sim для каждого сюжета: Jaccard + совпадения → выбирает лучший, например «Десять негритят» (ключевые: пропала, тайна, расследование, улика) score=1.2
  11. buildPlotGraph() → 5 стадий: завязка (пропала, преступление) → развитие1 (улика, коробка пиццы) → развитие2 (подозреваемый, перо ворона) → кульминация (правда) → развязка (справедливость)
  12. Генерирует текст по этим стадиям, используя enrichedKeywords = вступление + лучший сюжет + жанровые слова, с Coherence проверкой и диалогами-цепью Маркова
  13. В начале текста лог: [Мат.модель: выбран сюжет "Десять негритят" жанр Детектив score=1.20 совпадения: пропала, тайна]
